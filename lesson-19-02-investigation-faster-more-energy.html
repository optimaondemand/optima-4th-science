📘 The Lesson: How Scientists Build Evidence
Controlled tests, multiple trials, careful measurements
⏱ 15 min

Part 1 · What Makes a Test "Fair"?

You learned in 19.01 that faster objects carry more energy. Today's job is to PROVE it with your own evidence. Real proof needs a fair test, which scientists call a controlledControlled testOnly one thing changes; everything else stays the same. test. In a controlled test, you change ONE thing at a time and keep everything else the same.

If you change two things at once, you won't know which one caused the difference. Imagine rolling a HEAVIER ball at a FASTER speed and saying “the energy was bigger because of the speed!” You can’t be sure. It could have been the weight. That's why controlling variables matters.

Part 2 · Multiple Trials & Measurements

Once your test is set up fairly, you run multiple trialsTrialOne run of a test., usually at least 3, and more if you can. Why? Because one trial could be a fluke. Five trials show a pattern.

Each trial, you take a measurementMeasurementA number from a tool.: a number you can record with a ruler, a stopwatch, or another tool. The two most useful measurements in a speed test are:

  • DistanceDistanceHow far something moves.: measured with a ruler. How far did the target move?
  • TimeTimeHow long something takes.: measured with a stopwatch. How long did the ball take to reach the bottom of the ramp?

If you know both, you can figure out speedSpeedHow fast something moves. (distance ÷ time). And if you change the speed across trials, you can see the energy effect for yourself.

Watch out: Some people think one trial is enough if it “looks right.” Real scientists run many trials, so their answer comes from a pattern, not one lucky moment.

Q1

What is a TRIAL in a science investigation?

AWhen a scientist gets in trouble
BOne run of a test
CA measurement of speed
🔁 Right! A trial is one run-through of your test. Scientists run multiple trials to spot patterns.
A trial is ONE RUN of your test. Scientists do multiple trials — sometimes 3, sometimes 100 — so they don't accidentally trust a lucky result.
Q2

What makes a test a CONTROLLED test?

AOnly one thing changes at a time — everything else stays the same
BThe test is done in a classroom
CThe scientist controls the result
🎛️ Right! A controlled test changes only ONE thing — that's how you know what caused the difference.
A controlled test changes ONLY ONE thing at a time while keeping everything else the same. That's how scientists figure out what causes a result.
Q3

In a marble-ramp investigation, you want to test the effect of SPEED on how far a target moves. What's the ONE thing you should CHANGE between trials?

AThe size of the marble
BThe target object
CThe ramp height (which changes the marble's speed)
📏 Right! Change the ramp height to change the speed. Keep the marble and target the same so your test is fair.
If you want to test the effect of SPEED, you should change something that controls speed (like ramp height). The marble and target should STAY THE SAME so they don't affect the result.
